# Task Manager

Task Manager is a simple Python console application that allows users to manage their daily tasks. It includes password protection and automatically saves tasks in a JSON file, so they remain available when the program is restarted.

## Features

- **Master Password:** Users must enter a password to access the application.
- **Password Generator:** Generates a random 12-character password.
- **Password Strength Checker:** Checks whether a password is weak, medium or strong.
- **Add Tasks:** Create new tasks.
- **View Tasks:** Display all saved tasks.
- **Delete Tasks:** Remove tasks by their number.
- **Task Completion:** Mark tasks as completed.
- **JSON Storage:** Automatically saves tasks in `tasks.json`.
- **Input Validation:** Handles incorrect menu choices and invalid task numbers.

## Technologies Used

- Python 3
- `json` – saving and loading tasks.
- `random` – generating random passwords.
- Git – version control.
- GitHub – repository hosting.

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python task_manager.py
```

5. Create your master password.
6. Enter your password to access the menu.
